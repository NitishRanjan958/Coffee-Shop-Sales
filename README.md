🎯 Objective

The objective of this project is to transform raw coffee shop sales data
into an interactive and easy-to-understand Excel dashboard that
provides useful business insights and supports data-driven
decision-making.

📌 Key Insights

The dashboard provides a visual overview of:

Sales trends based on operating hours

Sales contribution by product category

Order distribution by product size

Store location performance

Top-performing products

Weekday-wise order patterns
